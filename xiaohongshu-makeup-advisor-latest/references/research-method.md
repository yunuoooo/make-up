# 研究与推荐方法

## 1. 建立妆容指纹

按实际相关性检查这些维度，不必机械地逐项输出：

| 维度 | 观察重点 |
| --- | --- |
| 底妆 | 哑光/奶油/水光，遮瑕度，厚薄，是否保留皮肤纹理，定妆范围 |
| 眉毛 | 粗细、弧度、毛流、颜色、眉峰和眉尾走向 |
| 眼影 | 主色、冷暖、明度、饱和度、晕染边界、眼皮与下眼睑的落点 |
| 眼线与睫毛 | 线条粗细和上扬度，内外眼线，睫毛束感、密度、长度与卷翘 |
| 腮红 | 色相、明度、位置、范围、形状，以及与修容的关系 |
| 修容与高光 | 骨相方向、明暗对比、光泽颗粒和高光位置 |
| 唇妆 | 色相、冷暖、明度、饱和度、透明度、边界、哑光/镜面质感 |
| 整体 | 对比度、色彩数量、视觉重心、留白、氛围、镜头/现实适用度 |

把每个核心视觉特征写成能挑选产品的规格。例如，“低饱和灰粉眼妆”应转换为“偏灰、不发橙、低到中显色度、易叠加的冷粉/灰棕盘”，而不是直接跳到品牌名。

输出时把妆容指纹压进特点与选品拆解表，不再另写一套逐部位总结。每个可观察特点只保留一行；整体风格只在表前用一句话概括，变体与争议集中说明。

## 2. 设计站内搜索

从用户用词生成少量互补查询：

- 风格主查询：`<风格名> 妆容`、`<风格名> 教程`。
- 产品查询：`<风格名> 产品/好物/眼影/腮红/口红`。
- 适配查询：加入肤质、肤色、单眼皮/双眼皮、眼镜、通勤、婚礼、上镜等真正相关的条件。
- 别名查询：只加入从结果中确认存在的常用别称，不自行发明趋势名称。

搜索结果应覆盖教程、近距离妆效、产品清单或试色，不要只看标题相似的成片。搜索结果每条只有标题、作者、互动数和一段约 60 字的**截断预览**：预览只用来筛掉明显不相关的条目，**不能当正文**，判断特征必须靠打开后的正文和画面。

第一轮用于建立通用妆容指纹，不因缺少个人条件而暂停。第二轮复用首轮结论，只对肤质、肤色、预算、发色、假睫毛接受度或风格分支会改变的品类追加搜索；不要机械重读所有通用笔记。

## 3. 评估证据

优先级从高到低：

1. 多位独立创作者反复出现、且画面或步骤能验证的特征。
2. 有清晰上脸、试色、使用步骤或产品标注的单篇教程。
3. 只有成片、标题或口头断言的笔记。
4. 明显商业合作、店铺带货或无法确认产品身份的内容。

至少记录标题、创作者、可见日期、站内复搜关键词、支持的特征和是否疑似商业内容。两位以上独立创作者重复出现可称为“常见特征”；单篇观点应标为“个别笔记做法”。点赞量只表示传播度，不证明产品适合用户。

## 4. 从特征映射到产品

依次检查：

1. 产品类别是否真的影响该特征；能靠手法或现有产品完成时，不强行推荐购买。
2. 色调、明度、饱和度、显色度、光泽、遮盖力、持妆方式是否匹配。
3. 用户肤质、肤色深浅与冷暖、敏感项、熟练度是否匹配。
4. 预算、购买地区、容量和使用频率是否合理。
5. 色号、版本、名称、在售状态和价格是否能从当前可靠页面确认。
6. 用户是否已明确确认拥有这件具体产品；只有完整产品身份可核对且规格匹配时，才能把购买结论写为 `✅`。

“同款”仅用于小红书笔记明确展示或写明的产品；“匹配型”表示基于产品属性的推导；“平替”需要同时说明相似点与不可替代的差异。

## 5. 特点与选品拆解表

把结果分成两个独立 section，先必要、后非必要；不要用一张混合表，也不要增加“必要性”列：

### 必要：特点与选品拆解

| 区域 | 目标特点 | 用什么达成 | 怎么选与怎么做 | 购买结论与具体产品/路线 |
| --- | --- | --- | --- | --- |
| 全脸或具体部位 | 可直接观察的妆效 | 产品类别、工具与必要动作 | 色调、质地、遮盖力、显色度及关键画法 | `💰 品牌｜完整产品名｜版本/色号｜证据类型` 或 `✅ 品牌｜完整产品名｜版本/色号｜证据类型` |

### 非必要：特点与选品拆解

使用与“必要”相同的五列，只放取决于个体条件、场景或风格分支的增强项。没有可靠的非必要项时，可以写“本轮没有需要额外增加的非必要项”，不为凑表添加商品。

表内排序和去重规则：

- 先列“全脸底妆”作为总底层，再按额头（仅在相关时）、眉毛、眼窝/眼影、眼线/睫毛、鼻部、中庭/面颊、颧骨/轮廓、嘴唇、下巴（仅在相关时）的顺序排列。
- 跳过与目标风格无关的区域，不因顺序存在就虚构特征。
- 每个目标特点只出现一次。例如“混血上扬眉”只在眉毛行说明眉笔、眉粉、染眉膏或眉胶如何共同完成，不把毛流、颜色和眉尾拆成重复行。
- 多个产品、工具或动作共同完成一个特点时，全部放进同一行；同一产品影响多个部位时，放在贡献最大的那一行，并在其他行用简短交叉引用，避免重复推荐。
- “目标特点”已经说明视觉作用，因此默认不再单设“作用”列。“用什么达成”写品类和工具，“购买结论与具体产品/路线”写可识别的具体商品和结论，两列不得换词重复。

购买标记和产品身份规则：

- 两表之前固定写图例：`💰 需要购买｜✅ 用户已确认拥有`。标记描述的是当前选中具体单品的持有状态，不能替代“必要/非必要”对妆效的分类。
- `💰` 表示如果采用当前推荐的具体单品，需要新增购买。首轮没有用户现有彩妆清单时，具体候选默认使用 `💰`，并说明用户已有同类单品时可在第二轮核对替换；这不等于断言用户没有同类产品。
- `✅` 仅用于用户明确说出或展示、且能核对完整身份的具体产品。不得因为用户泛称“我有眼影”“有一支豆沙口红”就推断为 `✅`。
- 每件单品分别写一个标记，并紧跟“品牌｜完整产品名｜版本/色号｜证据类型”。同一格有多个单品时逐行列出，不用一个标记笼统覆盖整组产品。
- 不得只写“现有眼影”“手边同类腮红”“任意棕色眉笔”等模糊路线。现有产品身份不完整时，在个性化阶段请求包装照片或完整品名；在确认前不伪造 `✅` 结论。
- 缺少试色依据时仍要给出具体产品，但版本/色号位置写“色号待试：<范围或判定方法>”，尤其不得为粉底、遮瑕或有色唇妆编造精准色号。
- 非必要表里的 `💰` 仅表示用户选择该增强项时需要购买，不代表该商品是完成妆容的必买项。

- “必选”只用于缺少后会明显失去该妆容辨识度的基础步骤。某一特征能用已核对的用户现有产品实现时，把该具体产品标 `✅`，不再把新购商品列为当前路线。
- “可选”用于取决于肤质、脸型、眼型、场景和持妆需求的步骤。遮瑕/校色、散粉、高光、古铜粉、唇线等通常按实际需求判断；双眼皮贴和美瞳默认列为可选。
- 假睫毛按目标分支判断：当多篇样本都依靠眼尾渐长或成束睫毛构成猫眼等核心识别点时，把“眼尾睫毛结构”列为必选妆效，并把假睫毛列为优先实现路线。是否把假睫毛商品列为最终必选，还要结合用户自然睫毛条件和接受度；不要把某个风格分支的结论扩展成所有妆容的通则。
- 必要性描述的是完成妆效的步骤，不等于必须购买指定品牌。若用户的个体条件或指定变体改变了必要性，明确写出原因。
- 粉底一行必须分别说明目标妆效、适合的色调/遮盖力/妆效质地，以及它在统一肤色、保留原生感或控制光泽方面的作用。
- 首轮没有试色依据时，不给粉底或遮瑕绝对色号。个性化阶段每个关键品类默认给 1 个首选；只有预算、质地或购买便利存在明确差异时，增加 1 个备选。

每个关键品类都要在“购买结论与具体产品/路线”中给出可识别的具体单品。信息较多时可增加这些列：

- 产品、版本和色号（若能确认）
- 适合与不适合的人/条件
- 证据类型：小红书同款、特征匹配或替代
- 价格带与购买地区（仅在可确认时）

最终附上来源列表和研究日期。新增购买总价只合计 `💰` 项，`✅` 项不重复计价；必要表与非必要表的 `💰` 分开说明，避免把增强项误写成必买。来源列表写标题、创作者、可见日期和站内复搜关键词：**本轮不给可点链接**（拼出来的 `/explore/<id>` 打不开），也不要自己拼。

## 6. 整体妆效图与视觉证据

默认按这个阅读顺序输出：

1. 用一句话概括整体妆效。
2. 放一张能同时看清整体色彩、质地和视觉重心的完成妆画面。
3. 完整输出“必要”拆解表，再输出“非必要”拆解表；不在每一行之间插图。

整体图必须来自本次或同一轮研究中实际返回的有效小红书笔记：

- 图片只能是搜索结果或详情实际返回的那些：详情给图组，搜索只给封面。**视频笔记只有封面**，拿不到画面帧；封面可能带文字贴纸、也不是完成帧——选图时把这一点算进去。
- 图片紧邻标注笔记标题、创作者和站内复搜关键词（本轮不给可点链接）。图片证明的是可见妆效；只有笔记明确展示或写明时，才把它作为具体产品证据。
- 默认不提供逐部位截图。用户明确要求核验某个局部结论时，才补充能证明该结论的最少量局部截图，并避免把表格内容逐字重复一遍。
- 截图只作为分析所需的视觉证据，不下载或复刻整篇内容。无法取得可靠整体图时明确说明，不换用无关图片。
- 如果用户要求耗时，记录每篇笔记的实际检查与提取时长；从既有画面重排版式不算一次新的扒取。
