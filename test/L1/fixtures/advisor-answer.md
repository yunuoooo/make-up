## 决定妆效的执行顺序

1. 保湿/妆前 → 橘调校色压黑眼圈 → 米色提亮打底 → 薄涂润型粉底 → 面中蜜粉定哑光。
2. **轮廓**：膏状修容打底 → 粉状修容小范围加强 → 提亮面中。
3. **眉毛**：眉粉勾形 → 细芯眉笔补毛流 → 染眉膏轻扫。
4. **眼妆**：暖棕铺眼窝 → 加深眼尾 → 眼线与假睫毛。
5. **腮红**：膏状打底 → 同色粉状叠加 → 内轮廓轻提亮。
6. **唇妆**：唇线整理轮廓 → 薄涂裸棕唇釉 → 唇中叠透明唇蜜。
